# ศาศวัต ห้องเย็น — ต้นแบบระบบปฏิบัติงาน

เปิด `SMIT-Prototype.html` ด้วย Chrome หรือ Edge ได้โดยไม่ใช้ Terminal ตัวไฟล์รวมโค้ด รูปแบบ และฟอนต์ไว้แล้ว ข้อมูลบันทึกในเบราว์เซอร์ของเครื่องนั้น การส่งไฟล์ให้คนอื่นจะเป็นต้นแบบที่ข้อมูลแยกกัน ไม่ใช่ฐานข้อมูลร่วมกัน

เลือกบทบาทที่มุมล่างของเมนู: พนักงานขาย พนักงานคลัง ผู้ดูแลห้องเย็น หรือผู้จัดการ หน้าหลักจัดงานเร่งด่วนตามบทบาท เริ่มจากสร้างคำสั่งซื้อ ตรวจสต๊อก หรือจัดการห้องเย็นได้โดยตรง

## งานที่ลองได้

- รับคำสั่งซื้อจากหน้าร้าน โทรศัพท์ LINE และออนไลน์ ค้นหาลูกค้า เพิ่มลูกค้า เลือกสินค้า ตรวจจำนวนและล็อต ยืนยัน จัดสินค้า ส่งหรือรับหน้าร้าน และยกเลิกพร้อมคืนสต๊อก/แต้ม
- ดูสต๊อกแยกล็อต รับเข้า เบิกออก ตรวจนับ ปรับจำนวนพร้อมเหตุผล ค้นหาบาร์โค้ดจำลอง และกรองสินค้าใกล้หมด/ใกล้หมดอายุ/หมดอายุ
- ดูอุณหภูมิห้องเย็น จำลองค่าผิดปกติ รับทราบเหตุ บันทึกการแก้ไข ปิดเหตุ และผูกสินค้าเสียกับเหตุการณ์
- ดูประวัติลูกค้า กลุ่มลูกค้า ราคาพิเศษ แต้มสะสม การแนะนำลูกค้า และสร้างโปรโมชั่นพร้อมตรวจรายชื่อก่อนส่งจำลอง
- จัดส่ง สั่งซื้อจากผู้ขาย ติดตามลูกค้า ข้อร้องเรียน แบบประเมิน พนักงาน การอบรม การแจ้งเตือน รายงานยอดขาย และผลการดำเนินงาน
- สำรอง/นำเข้าข้อมูล และกำหนดนโยบายการหยิบสินค้า/กลุ่มลูกค้า/แต้ม

ข้อมูลเริ่มต้นมีสินค้า 20 ชนิด ลูกค้า 20 ราย คำสั่งซื้อ 36 รายการ ห้องเย็น 3 ห้อง เหตุการณ์ 5 รายการ และโปรโมชั่น 5 รายการ ใช้วันที่ตัวอย่าง 2 ตุลาคม 2026 เพื่อให้สถานการณ์ทดลองคงที่

## ขอบเขตต้นแบบ

เป็นต้นแบบเชิงโต้ตอบ ไม่มีระบบเข้าสู่ระบบ ฐานข้อมูลกลาง การรับชำระเงิน หรือการเชื่อมเครื่องวัดจริง การเลือกบทบาทเป็นตัวอย่างหน้าจอ การส่ง LINE/SMS และขนส่งเป็นการจำลอง ไม่มีข้อความส่งออกจริง ข้อมูลที่วัดไม่ได้จะแสดงว่ายังไม่มีข้อมูล ไม่สร้างตัวเลขขึ้นเอง

## สำหรับพัฒนาต่อ

ใช้ Next.js, React, TypeScript, Tailwind, Lucide และ Recharts โดยออกแบบส่วนประกอบและสไตล์เอง

```sh
npm ci
npm run dev
npm run test
npm run typecheck
npm run build
```

เซิร์ฟเวอร์พัฒนาเปิดที่ http://127.0.0.1:4175 ส่วน `dist/` เป็นเว็บที่ build แล้วสำหรับ static server

โค้ดหน้าจออยู่ใน `src/components/` กฎธุรกิจอยู่ใน `src/lib/domain.ts` และการคำนวณรายงานอยู่ใน `src/lib/metrics.ts` รายละเอียดการออกแบบและผลตรวจอยู่ใน `DESIGN-AND-VERIFICATION.md`
